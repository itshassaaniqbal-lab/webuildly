# Buildly

Buildly is a premium, production-ready agency website built with Next.js, React, TypeScript, Tailwind CSS, Framer Motion, GSAP, Three.js, React Three Fiber, Drei, Lenis, Radix UI (the interaction primitive used by shadcn/ui), and Lucide React.

## Features

- Interactive, mouse-responsive 3D digital core with scroll-driven transformation
- Cinematic loading screen, smooth Lenis scrolling, parallax depth, and motion reveals
- Responsive layouts for mobile, tablet, desktop, and ultrawide displays
- Premium service, work, process, testimonials, FAQ, and contact experiences
- WhatsApp-first conversion flow with a formatted project brief
- SEO metadata, Open Graph and X cards, sitemap, and robots directives
- Reduced-motion support, semantic landmarks, keyboard-friendly controls, and labelled forms
- No backend, database, authentication, CMS, or deployment configuration required

## Local development

Requirements: Node.js 20.9 or later and npm.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. In Vercel, select **Add New → Project**.
3. Import the GitHub repository.
4. Keep the detected **Next.js** framework settings unchanged.
5. Select **Deploy**.

No environment variables or additional setup are needed.

## Customization

The main content is organized by section in `components/`. Brand colors, layout tokens, and global visual styling live in `app/globals.css`. Project previews are original code-rendered visuals, so they can be replaced with production screenshots later without external image dependencies.
